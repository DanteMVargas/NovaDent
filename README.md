# 🦷 NovaDent Lima Centro - Landing Page Odontológica
> Desarrollado con **React**, **Node.js**, **pnpm**, **TypeScript**, **Tailwind CSS** y componentes de **shadcn/ui**.

---

## 🎨 Paleta de Colores
- **Blanco Higiénico y Médico (`#FFFFFF` / `bg-background`)**: Base limpia, pulcra y luminosa.
- **Azul Dental Profesional (`#0284C7` / `#0369A1` / `#E0F2FE`)**: Inspiración clínica, confianza médica y rigor técnico.
- **Verde Menta Salud (`#10B981` / `#059669` / `#ECFDF5`)**: Acentos de bienestar, salud bucal y llamadas a la acción directas hacia WhatsApp.

---

## 📍 Datos de Contexto (Centro de Lima, Perú)
- **Sede:** Jr. Carabaya 450, Piso 3, Centro Histórico de Lima *(a 1 cuadra de Plaza San Martín)*.
- **Accesibilidad:** A 2 minutos a pie de la **Estación Jirón de la Unión del Metropolitano** y Corredor Tacna.
- **Precios en Soles (S/.):**
  - Blanqueamiento Láser Zoom + Profilaxis: **S/ 189** (50% DCTO).
  - Ortodoncia y Brackets: Cuotas desde **S/ 99/mes** (Diagnóstico 3D gratis).
  - Implantes de Titanio con Corona: **S/ 1,399**.
  - Pack Prevención y Limpieza Ultrasonido: **S/ 69**.
- **Medios de Pago Peruanos:** Yape, Plin, BCP, BBVA, Interbank, tarjetas de crédito hasta 12 cuotas sin interés.
- **Certificaciones:** Odontólogos Colegiados (COP) y Registro Nacional de Especialistas (RNE).

## 🧱 Componentes shadcn/ui Utilizados
- `Button` (`@/components/ui/button`): Variantes personalizadas (`dentalBlue`, `dentalGreen`, `dentalDual`, `outline`).
- `Dialog` (`@/components/ui/dialog`): Modal interactivo de reserva de citas conectado con generador a WhatsApp.
- `Accordion` (`@/components/ui/accordion`): Sección interactiva de Preguntas Frecuentes (FAQ).
- `Card` (`@/components/ui/card`): Tarjetas de promociones, servicios y opiniones.
- `Badge` (`@/components/ui/badge`): Etiquetas de descuentos y procedencia.
- `Input` & `Label` (`@/components/ui/input`, `@/components/ui/label`): Campos accesibles del formulario de citas.

## 🛠️ Comandos de Desarrollo (usando `pnpm`)

### Iniciar el servidor de desarrollo
```bash
pnpm dev
```
Abre tu navegador en `http://localhost:5173`.

### Compilar para producción
```bash
pnpm build
```

### Previsualizar la versión de producción
```bash
pnpm preview
```
